# Row 7 Cinemas — 3D «θέα από τη θέση»

Demo ιστοσελίδας κράτησης εισιτηρίων σινεμά (φανταστική αλυσίδα και ταινίες) με μια
επιπλέον λειτουργία: **όταν διαλέγεις θέση, βλέπεις σε 3D πώς θα φαίνεται η οθόνη
ακριβώς από εκείνη τη θέση.**

## Τι κάνει
- Επιλογή ημέρας, ταινίας και προβολής.
- Χάρτης αίθουσας (σειρές A–L, διάδρομοι, VIP, θέσεις ΑμεΑ, κατειλημμένες θέσεις).
- **Live 3D προεπισκόπηση**: περνώντας το ποντίκι (ή πατώντας) πάνω σε μια θέση, η κάμερα
  μεταφέρεται στο ύψος των ματιών ενός καθήμενου θεατή σε εκείνη τη θέση.
  - Ίδια γεωμετρία σε μέτρα για χάρτη και 3D (οθόνη 14 m, scope 2.39:1, stadium σκαλιά).
  - Σταθερό οριζόντιο οπτικό πεδίο 80°, ώστε το μέγεθος της οθόνης να συγκρίνεται σωστά σε κάθε συσκευή.
  - Θεατές στις κατειλημμένες θέσεις (με διακόπτη) για να φαίνεται αν σε κρύβει κάποιο κεφάλι.
  - Σύρσιμο για να κοιτάξεις γύρω, βελάκια για να αλλάξεις θέση, Enter για επιλογή, πλήρης οθόνη.
- Μετρικές ανά θέση: απόσταση, γωνία θέασης (SMPTE/THX ~36–45°), πλάγια απόκλιση,
  κλίση αυχένα, και συνολικό σκορ 0–100.
- Καλάθι με τιμές και οθόνη επιβεβαίωσης (χωρίς πραγματική πληρωμή).

## Εκτέλεση
Στατικό site, χωρίς build. Χρειάζεται τοπικό server (λόγω ES modules):

```bash
python3 -m http.server 8000
# άνοιξε http://localhost:8000
```

Το three.js (`three@0.160.0`, MIT) περιλαμβάνεται στο `js/vendor/`, οπότε δεν φορτώνεται τίποτα από εξωτερικό CDN.

## Δομή
- `index.html`, `styles.css` — UI
- `js/hall.js` — γεωμετρία αίθουσας, θέσεις, μετρικές θέασης
- `js/seatView3d.js` — 3D σκηνή (three.js) και κάμερα θέσης
- `js/app.js` — ροή κράτησης, χάρτης θέσεων, σύνδεση με το 3D

## Προσαρμογή σε πραγματική αίθουσα
Άλλαξε τις τιμές στο `HALL` (`js/hall.js`): πλάτος οθόνης, απόσταση πρώτης σειράς,
βάθος/ύψος σκαλιού, μπλοκ θέσεων ανά σειρά. Ο χάρτης και το 3D προσαρμόζονται αυτόματα.

## Extension για demo πάνω σε πραγματικά sites
Ο φάκελος [`extension/`](extension/README.md) περιέχει ένα browser extension (Chrome/Edge) που προσθέτει την
3D θέα από τη θέση πάνω στη σελίδα επιλογής θέσεων υπαρχόντων sites σινεμά, μόνο στον δικό σου browser,
για παρουσίαση της ιδέας.
